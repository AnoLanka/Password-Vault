# Password Vault

A password management application developed as my **OCR A-Level Computer Science NEA project** using **Python, Tkinter and SQLite**.

The application allows users to securely manage their stored account credentials through a graphical user interface. It includes user authentication, password categorisation and database management.

## Features

- User account creation and authentication
- Secure password storage within a SQLite database
- Add, view, edit and delete saved passwords
- Categorise passwords for easier organisation
- Graphical user interface built with Tkinter
- User-specific data management
- Input validation and error handling

## Technologies Used

- **Python** - Language of code
- **Tkinter** – Graphical User Interface
- **SQLite** – Database management

## Project Structure

The application is divided into multiple pages and components, including:

- Authentication and account creation
- Category management
- Password management
- Database interaction
- User-specific data handling
